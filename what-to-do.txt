- Search overhaul — algorithm and layout (HIGH PRIORITY)
  - Algorithm problems:
    - Exact/prefix match on artist name should rank far above substring matches from unrelated fields
    - Searching "Ye" shows ABBA, Aesop Rock, A Perfect Kiss before Ye (the artist) — prefix match on artist name must beat partial matches elsewhere
    - Tracks section spammed with tracks from albums whose title starts with "&" or "Y" (e.g. Do Make Say Think's "& Yet & Yet") — track results should rank by artist/title relevance, not album title match
    - Albums section: searching "Ye" buries Ye's own albums behind "& Yet & Yet", "2093" (Yeat), "Alive 2007" (Daft Punk), "Almighty So" (Chief Keef) — album title prefix match should not beat artist name match
    - Ranking priority should be: exact name match > prefix match on primary field (artist name / album title / track title) > artist match on secondary results > substring anywhere
  - Layout problems:
    - Artists section requires scrolling to reach despite large unused whitespace — artists should appear at top, immediately visible
    - Each section shows only a few results then hides behind "More" — layout should use available window space to show more results without requiring clicks
    - Window space wasted; results cramped into a narrow column
  - Goals:
    - Relevance-ranked results: best match type first (exact > prefix > fuzzy), primary field weighted higher than secondary
    - Artists pinned to top of results
    - Layout fills the search window — use a multi-column or card-based layout that takes advantage of the full width
    - "More" fallback only for truly long tails, not for the primary 5-10 results
    - Artist results are not clickable — clicking an artist in search results should navigate to that artist's page

- Clicking a genre tag on an album (opened from Home) navigates to Home instead of Library filtered by that genre

- For You cards (all except Jump Back In and On Repeat) don't pick fresh albums on refresh — they just shift the queue by one
  - e.g. refresh 1: [A1, A2, A3, A4] → refresh 2: [A2, A3, A4, A5] → refresh 3: [A3, A4, A5, A6]
  - Should pick 4 genuinely new albums each refresh, not advance a sliding window

- Clicking artist name in Album detail view should navigate to that artist's page
- In the Spotlight section on Home, clicking the artist name should navigate to that artist's page

  - Needs design work: how filters combine (AND? tag-style multi-select?)
  - Needs design work: UX for adding — button in popup opens a builder, user names it, picks filters, saves as a new entry alongside built-ins
