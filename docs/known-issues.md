## Platform / WebKitGTK / audio

- **Popups self-close on their own clicks: on WebKitGTK, and when portaled outside the watched ref.** The opening click's tail reaches the outside-click listener. Use `useClickOutside` (deferred attach, capture `mousedown`), no local copies. A portaled popup is outside its wrapper: the genre mapping and new-node parent pickers watched only the input's, so pressing a row closed the list before it saved (Unmatched genres never mapped); pass the portal's ref too. grep: `grep -rn 'addEventListener("mousedown"' src --include='*.ts*' | grep -v '\.test\.'; for f in $(grep -rln "useClickOutside(" src --include='*.tsx' | grep -v '\.test\.'); do grep -l createPortal "$f"; done`
- **Focus-loss compositor crash is upstream `wry`; keep the mitigations.** `web-process-terminated` → `.reload()`, `useAppActivityTracking` blur stamp, `webkit2gtk-nvidia-quirk`, `"visible": false` + `window.show()` on load; WebKit smooth scrolling stays off (suspected trigger). Never touch `set_hardware_acceleration_policy` blind.
- **ALSA underruns under load.** rodio 0.19 took the ALSA plugin's too-small default buffer. `open_output` asks for a fixed 100ms (its fallback, rodio's fixed 50ms); a system-default buffer is what broke rodio 0.22. Not cpal's `pulseaudio` host: it names the client `cpal-pulseaudio-<pid>`, so the mixer forgets Canon's volume every launch. grep: `grep -rn "BufferSize::Default" src-tauri/src`
- **A player on a dead output stream never drains, so nothing ends and nothing errors.** rodio 0.23's `Player::connect_new` can't fail, and the old sink-creation error was the only "device unavailable" report; `open_output`'s error callback sets `output_lost` on a fatal stream error, checked at play start and by the watcher. grep: `grep -rn "connect_new\|with_error_callback" src-tauri/src`
- **rodio's `Decoder::new` can't seek backwards.** Since 0.21 it marks the reader unseekable; build through `open_decoder` (seekable + byte length). grep: `grep -rn "Decoder::new" src-tauri/src`
- **Read-only rusqlite can't own the WAL `-shm`.** `library_read/mod.rs` opens `READ_WRITE | NO_MUTEX | URI`, no `CREATE`.
- **Unbounded thread-per-request gets SIGKILLed.** Cover proxy takes a permit before spawning, `spawn_blocking`, cap 16. Tell: `ps -eLf | grep canon | wc -l` climbing.
- **Two HTTP stacks = two proxy configs and two certificate stores.** API calls go through libsoup (GProxyResolver, PAC), covers through reqwest (env proxy); `/system/proxy/mode` = `auto` with a dead PAC stalls every `fetch` 25s. reqwest on bundled webpki roots failed a private-CA server the webview trusted; now `rustls-tls-native-roots`. Ask of any transport failure: which client saw it, would the other agree? grep: `dconf read /system/proxy/mode; grep -n "rustls-tls\|native-tls" src-tauri/Cargo.toml`
- **"Something answered" is not "the right thing answered".** `probe_server` called any HTTP response reachable (404, 502, 407). Only 2xx earns "up"; a boolean built from "no error" answers a narrower question than its name.
- **A diagnosis used only for message text is not a decision.** The breaker got a 2xx probe, wrote it in the notice, and opened anyway. First 2xx probe in a streak closes it. grep: `grep -rn "probe_server\|ServerProbe" src --include='*.ts*' | grep -v '\.test\.'`
- **WebKit's `err.stack` has no message line.** Logging the stack alone lost every message; `formatLogValue` prefixes `name: message`. grep: `grep -rn "\.stack" src --include='*.ts*' | grep -v '\.test\.'`
- **WebKitGTK keeps showing a layout after it should change, until an unrelated repaint.** New tabs in an `overflow-x: auto` list clipped until hover (key the list on the toggle so it remounts). Narrow Now Playing stayed side by side after a resize crossed a `max-height` media query until a click or focus switch, and remounting on the computed style didn't help (the style was stale too); view layouts use `@container` queries. Not reproducible in jsdom. grep: `grep -rn "@media (max-height\|@media (min-height" src --include='*.css'`
- **A `box-shadow` ring extends past its element's box; `overflow-x: auto` clips it there.** `.artist-similar-strip` had `padding-bottom` only, so the owned-artist accent ring was cut off at the top; pad every side the ring can bleed into, not just the one that looked wrong.
- **"Load failed" after ~25s is usually systemd-resolved.** Check `resolvectl status` / `journalctl -u systemd-resolved` first. Hardening: 12s `AbortController`, 3 retries, non-fatal `skippedStages`.
