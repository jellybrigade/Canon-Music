# Product

## Register

product

## Users

Self-hosters running their own Navidrome server. Playback is the primary daily use — Canon behaves like a real desktop music player, used continuously in the background. Tag and metadata management (genre normalization, artist enrichment, tag-issue cleanup) is a secondary but load-bearing workflow the same user dips into periodically to keep their library clean. Both modes matter; playback chrome must stay unobtrusive while tag/metadata screens must stay dense and precise.

## Product Purpose

Canon is a desktop client for self-hosted music servers that pairs a proper music player with local-only tag/metadata tooling (genre tree normalization, artist enrichment, tag-issue detection) — without ever writing back to the user's files. Success looks like: a player that disappears into daily use, and metadata tools that make a self-hosted library feel curated without manual file editing.

## Brand Personality

Precise, calm, capable. Understated tool-grade confidence — no flash, no marketing gloss. Reference feel: Spotify desktop's familiar player chrome + Navidrome-web's dense, no-nonsense list density.

## Anti-references

- Generic SaaS dashboard: no card-grid template, no gradient hero, no marketing-site polish creeping into app screens.
- Cluttered pro-audio tool (Mixxx/Audacity-style): no dense knob/meter overload, no cramming controls in for their own sake.

## Design Principles

1. Playback chrome disappears into daily use — the player bar and now-playing surfaces should feel invisible until needed, never competing for attention with the library.
2. Metadata/tag screens earn density — genre trees, tag-issue lists, and enrichment views can be information-dense where playback UI cannot.
3. Local-only, no false promises — enrichment and tag tooling never implies a file write; UI must never suggest an action mutates the user's music files.
4. Familiar over novel — lean on established music-player conventions (Spotify desktop, Navidrome-web) rather than inventing new interaction patterns for their own sake.
5. Calm confidence, not flash — restrained color strategy, purposeful motion, no decorative flourish.

## Accessibility & Inclusion

Standard WCAG AA: solid color contrast (body ≥4.5:1, large text ≥3:1), full keyboard navigation, respect for `prefers-reduced-motion`.
